# Age of Anything

A classic-style RTS where your civ is whatever you can describe.

Open the folder in Godot 4.7 and press Play. You get the **Race Lab**: type a race on each side
("centaur romans" vs "flying greeks with wings"), then Generate or Reroll, and watch the two armies.

- Design: `docs/design.md`
- Plan: `docs/mvp-plan.md`
- Working notes for Claude Code: `CLAUDE.md`
- Tests: `godot --headless --path . --script res://tests/run_tests.gd`
