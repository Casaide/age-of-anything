Getting started

A pack, a map and a body

Creel isn't public yet, so this page walks through the same steps inside Age of Anything's repository, with the commands as they are today. Everything you write is data, in a folder. When data isn't enough, a pack brings a few Lobster functions (hooks, planned).

Run commands from src/ unless they say otherwise. Lobster itself comes from its repository.

1. A pack

A pack is a folder (a zip to share) with a manifest. The scaffold writes one that passes the checks as it is, so you start green:

python3 tools/mods/new_mod.py zorbs --era scifi
mods/zorbs/
  mod.json                 the manifest
  data/
    lexicon.json           words that bring your units in
    parts.json             gear and bodies, each with its points
    rules/anything.json    opens your era under a host rule
    voxel/bodies/zorb.json a creature's body
    maps/crater.json       a map
  models/                  optional: models in Lobster
  sheets/zorbs.json        a sheet spec, to look at your units

The manifest names the pack, its version, what it depends on and how to check it:

{
  "id": "zorbs",
  "name": "Zorbs",
  "version": "0.1.0",
  "load_order": 100,
  "depends": [],
  "eras": ["scifi"],
  "data": "data",
  "check": { "rules": "anything", "prompts": ["zorbs with lasers"] }
}

Packs load in order of load_order, then id. An entry with the same id as one before it replaces it; "extends": "frog" copies an entry and changes only what you name. The pack's signature is id@version#hash, a sha256 over its sorted file paths and their bytes. Shared races name the packs they were made with, and (soon) lobbies and saves compare the list.

3. A body

A creature's body is named points, legs from a hip to a foot, and shapes on the points: capsules (cap … to), balls, and beads for eyes. Legs walk on their own: the engine solves the knee from the bone lengths and steps the foot by stride and lift. Materials are names (skin, pale, eye, the team colour) looked up in materials.json.

{
  "skin": "#e4dccb", "pale": "#2e2622", "size": 1.0, "fur": 0.12,
  "points": {
    "front": { "at": [0, 4.5, 11.5] },
    "back":  { "at": [0, -4.5, 11.5] },
    "head":  { "at": [0, 9.0, 14.0] }
  },
  "legs": [
    { "hip": ["front", 2.4, 0.5, -3.0], "foot": [2.4, 5.0, 1.0],
      "stride": 2.4, "lift": 1.4, "bones": [3.86, 3.86], "mats": ["skin", "pale"] },
    { "hip": ["back", 2.4, -0.5, -3.0], "foot": [2.4, -5.0, 1.0],
      "stride": 2.4, "lift": 1.4, "bones": [3.86, 3.86], "mats": ["skin", "pale"],
      "phase": 180 }
  ],
  "shapes": [
    { "cap": ["back", 0, 0, 0], "to": ["front", 0, 0, 0], "r": [5.6, 5.6], "mat": "skin" },
    { "ball": ["front", 0, 0.5, 2.5], "r": 4.4, "mat": "skin" },
    { "bead": ["head", 1.5, 1.0, 0.0], "r": 0.4, "mat": "eye", "mirror": true }
  ]
}

That is most of the sheep in data/voxel/bodies/sheep.json. A leg is drawn once and mirrored, so two entries give four legs. The body is voxelized and baked in eight facings when a match starts.

4. Buildings by role

The sim and the bots never look a building up by its id, only by what it does, so your buildings can be called anything. A building lists its roles:

RoleWhat it means
hubThe town's heart. A player who started with one is out when none is left.
housingWhat the bots build for room.
tradeBuying, selling, and trade carts between two of them.
barracksThe bots' first army building.
towerWhat the bots put up where they were raided.
defenceA strong point guarding a crossing.
wonderStood long enough, it wins.

A farm, a pen and a drop-off need no role: becomes, pen and drop_off say it. An unknown role stops the game at the start, with its name.

5. Hooks (planned)

When a pack needs behaviour the data can't say, it brings Lobster functions that are compiled in at start and called in load order. Rule hooks run in lockstep on every machine; UI hooks run on one. A sketch of a "last army standing" win, which today's data can't express:

// hooks/last_army.lobster: a rule hook (a sketch; names not final)
def victory() -> int:
    var alive = -1
    for(player_count()) p:
        if unit_count(p) > 0:
            if alive >= 0:
                return -1  // two or more still fighting
            alive = p
    return alive

Rule hooks keep to integers, the sim's own random numbers and a stable order; they may not touch files, the network, clocks or the window. The check tool lints them and plays a short match twice to see the state hash agree.

6. Check and share

src/mod_check.sh zorbs                      # loads it or says why not; races, placement, prices
src/sheet.sh mods/zorbs/sheets/zorbs.json /tmp/zorbs   # your units on a sheet, every facing
./play.sh lobby mods:zorbs rules:anything   # a match with it
python3 tools/mods/pack.py zorbs            # build/mods/zorbs-0.1.0.zip

A refusal says what to fix, by file and id. To install a pack, unzip it into mods/. Bump the version when you change it: a shared race names the packs it was made with.
