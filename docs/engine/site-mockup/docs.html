Get started

Your first pack

This guide builds a small pack: a map, a creature and a manifest. Then you check it and play it. Everything you write is data in a folder. When data can't say what you want, the pack adds a few Lobster functions, called hooks.

Run commands from src/ unless they say otherwise. Lobster itself comes from its repository.

1. A pack

A pack is a folder with a manifest, zipped when you share it. Start from the scaffold: it writes a pack that already passes every check, so you begin from something that works.

tools/mods/new_mod.sh zorbs --era scifi
mods/zorbs/
  mod.json                 the manifest
  data/
    lexicon.json           words that bring your units in
    parts.json             gear and bodies, each with its points
    rules/anything.json    opens your era under a host rule
    voxel/bodies/zorb.json a creature's body
    maps/crater.json       a map
  models/                  optional: models in Lobster
  sheets/zorbs.json        a sheet spec, to look at your units

The manifest says what the pack is called, its version, what it needs and how to test it:

{
  "id": "zorbs",
  "name": "Zorbs",
  "version": "0.1.0",
  "load_order": 100,
  "depends": [],
  "eras": ["scifi"],
  "data": "data",
  "check": { "rules": "anything", "prompts": ["zorbs with lasers"] }
}

Packs load by load_order, then by id. An entry with the same id as an earlier one replaces it, and "extends": "frog" copies an entry and changes only what you name. Each pack gets a signature, id@version#hash, where the hash covers every file in it. That is how a lobby knows all its players have the same rules, and how a save knows what it needs.

Bigger maps add heights (a digit per tile), animals and a symmetry. Put the file in your pack's data/maps/ and play it with map:<id>.

3. A body

A creature is a few named points, legs that run from a hip to a foot, and shapes hung on the points: capsules (cap to to), balls, and beads for eyes. You don't animate the legs. Creel works out the knee from the bone lengths and steps each foot by stride and lift. Colours are names like skin, pale and eye, so each team and skin can paint them differently.

{
  "skin": "#e4dccb", "pale": "#2e2622", "size": 1.0, "fur": 0.12,
  "points": {
    "front": { "at": [0, 4.5, 11.5] },
    "back":  { "at": [0, -4.5, 11.5] },
    "head":  { "at": [0, 9.0, 14.0] }
  },
  "legs": [
    { "hip": ["front", 2.4, 0.5, -3.0], "foot": [2.4, 5.0, 1.0],
      "stride": 2.4, "lift": 1.4, "bones": [3.86, 3.86], "mats": ["skin", "pale"] },
    { "hip": ["back", 2.4, -0.5, -3.0], "foot": [2.4, -5.0, 1.0],
      "stride": 2.4, "lift": 1.4, "bones": [3.86, 3.86], "mats": ["skin", "pale"],
      "phase": 180 }
  ],
  "shapes": [
    { "cap": ["back", 0, 0, 0], "to": ["front", 0, 0, 0], "r": [5.6, 5.6], "mat": "skin" },
    { "ball": ["front", 0, 0.5, 2.5], "r": 4.4, "mat": "skin" },
    { "bead": ["head", 1.5, 1.0, 0.0], "r": 0.4, "mat": "eye", "mirror": true }
  ]
}

That's most of a sheep. Each leg entry is mirrored, so two entries make four legs. When the match starts, Creel builds the body in voxels and draws it in eight directions.

4. Buildings by role

Creel and its bots find buildings by what they do, never by name, so yours can be called anything. A building lists its roles:

RoleWhat it means
hubThe town's heart. A player who started with one is out when none is left.
housingWhat the bots build for room.
tradeBuying, selling, and trade carts between two of them.
barracksThe bots' first army building.
towerWhat the bots put up where they were raided.
defenceA strong point guarding a crossing.
wonderStood long enough, it wins.

Farms, pens and drop-off points don't need a role: becomes, pen and drop_off already say what they are. A misspelt role stops the game at the start and names it.

5. Hooks

When your game needs something the data can't describe, write a hook: a Lobster function in your pack, compiled in when the game starts. Rule hooks run inside the simulation on every machine; interface hooks run on one. Here's a win condition, last army standing:

// hooks/last_army.lobster
def victory() -> int:
    var alive = -1
    for(player_count()) p:
        if unit_count(p) > 0:
            if alive >= 0:
                return -1  // two or more still fighting
            alive = p
    return alive

Rule hooks stick to whole numbers, the simulation's own random numbers and a fixed order, and they can't touch files, the network, the clock or the window. The checker reads them for anything that could make two machines disagree, then plays a short match twice to prove they don't.

The hook API is the next part of Creel to land. Names may still change.

6. Check and share

src/mod_check.sh zorbs                      # loads it or says why not; races, placement, prices
src/sheet.sh mods/zorbs/sheets/zorbs.json /tmp/zorbs   # your units on a sheet, every facing
./play.sh lobby mods:zorbs rules:anything   # a match with it
tools/mods/pack.sh zorbs            # build/mods/zorbs-0.1.0.zip

If something's wrong, the checker tells you what to fix, by file and id. To install a pack, unzip it into mods/. Raise the version whenever you change it, so players can tell your releases apart.
