# SG1: spider posture (2026-10-11)

Question for Dominic: how should a spider soldier stand? Bare heads, same spear unit, same legs.

- `spider_posture_close.png` (close up) and `spider_posture_game.png` (game size), left to right:
  1. **Today:** a big abdomen behind, head low in front, gear hung on the body.
  2. **Reared (`concept.spider_rear`):** the front body tilted up, the abdomen low behind, the
     front legs used as arms (the spear held up front).
  3. **Jumper (`concept.spider_jumper`):** a compact boxy body, a small abdomen, thick front legs.
  4. **Today at 60% size:** the cheap option, a smaller spider.

Claude's honest read: 2 and 3 read too alike at game size, because they share the long leg
part. Whichever is picked gets its own legs (shorter, thicker for the jumper). The reared one
gives a spear unit a clear "soldier" pose, so it's Claude's lean.
