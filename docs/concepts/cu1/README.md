# CU1: frogs, rethought (2026-10-11)

Built from what makes a frog (design review): eyes on top, never covered; a wide mouth line and
throat; long folded hind legs; gripping fingers with pads; wet, saturated skin. Models in
`scenes/art_pixel/concepts.gd` (`_concept_frog_[abc]_*`).

- **A, crouched leaper:** back sloping up from the rump, arms braced, hind legs folded high.
- **B, slim tree frog:** upright but lean, long limbs, big pads, side eyes.
- **C, bullfrog warrior:** low and broad, thick legs, a puffed throat sac.
