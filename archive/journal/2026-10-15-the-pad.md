# 2026-10-15: The pad

**Milestone:** 20 (Steam Deck and controllers), steps 3-6: the controls
**Who:** Dominic + Claude (Claude Code)

## What happened
Dominic: "lets get this ready to play on steam deck. Do a clean pass over the controls so we can use it with a
controller. We'll get it onto a steam deck afterwards." Milestone 20's design (2026-10-13) already said what kind of
pad game it should be: a reticle instead of a mouse, selection by area, one button per common job, menus that come up
when held. This session built it on the Mac; the Deck build and its measurements come next.

- **One layer for every screen** (`src/view/pad_mode.gd`): the last input wins (a pad press shows the pad HUD and hides
  the mouse; the mouse or a key brings the mouse game back, so the Deck's trackpad still works), the pads merged into
  one state, A and B added to the UI's accept and cancel, focus put into the menu that's up, Steam's keyboard on A in
  a text box (Linux), rumble.
- **The battlefield** (`src/view/pad_play.gd`): the left stick pans with the reticle riding along, the right stick
  nudges it (at the rim it pans), it snaps to a unit near it and shows the mouse game's cursor art for what X would do.
  Tap A selects, double-tap takes that kind on screen, hold A and a circle grows and sweeps up your units as you move.
  X is the smart order, Y attack-move, B backs out of anything. RB tapped takes the soldiers on screen (twice: all),
  LB tapped cycles the kinds, the d-pad finds idle workers, Town Centers and two control groups.
- **The wheel** (`src/view/pad_wheel.gd`): hold RB and the command panel's own buttons come up on a ring (pictures,
  costs, cards), picked by a stick; A picks and keeps it open (five workers in five presses), letting go picks the
  pointed one, LB turns pages. A build page stays up after you let go, so Build: Civilian, then the House, then A
  places it. With nothing selected it's a global wheel (idle worker, army, Town Center, alert, tech tree, pause).
  In pad mode the panel keeps only who's selected and the queue; a strip of button badges over the minimap says what
  the buttons do right now.
- **Menus:** every themed button can take focus now, with a lit rim in the culture's accent that only the pad (or the
  keys) shows; the lobby starts on Start Battle, X rolls the dice, Menu starts, B goes back; the pause menu starts on
  Resume (on the end screen, on Back to the menu); the tech tree scrolls on the sticks and closes on B.
- **A check that plays it:** `tests/pad_check.gd` drives a real match with a fake pad (21 checks: the Town Center on
  the d-pad, two workers from the wheel, the circle taking the workers and only yours, X on a bush, a house from the
  build wheel, one kind with LB, the pause menu's focus), with a picture at each look.

## Later: the first run on the Deck
The Linux templates were already installed, so a debug build went over the same evening (SMB from the Mac; Dolphin's
`afc:/` turned out to be for iPhones). Dominic's notes and what came of them:
- **"UI not scaled to it"**: the Start button was off the bottom. The UI never scaled below its 1600 x 900 design (it
  was made for big Mac screens); now it shrinks to fit a smaller window. Checked at 1280 x 800, lobby and HUD.
- **Simpler skins, no resource icons, no sound**: the funniest bug of the day. The game reads its SVGs, WAVs and GLBs
  as raw files, the Godot editor had been opened and "imported" them all, and an export then packs only the imported
  copies. On the Mac nothing looked wrong (the raw files are on disk); on the Deck every texture fell back to flat
  colour and the game went silent. All 323 asset files are now "keep" (exported as they are).
- **"The menu doesn't have controller support"**: unknown yet whether Steam passed a pad at all. The menus now also
  answer arrows and Enter, and the log lists the pads the game sees.
- **The wheel**: holding RB and steering with a stick was awkward and moved the camera. Now a tap of A on what you
  command opens it, the camera holds still (D-133). "Selection worked really well."
- **The army bake is slower**: expected on the Deck's CPU; the milestone's performance step.
- A crash on quit turned up on the way: a lambda listening for pads disconnecting was still hooked up when macOS
  reported them gone at exit. It's a method now, unhooked as the node leaves.
