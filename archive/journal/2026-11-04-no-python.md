# 2026-11-04: the Python goes

**What happened.** Dominic asked why we still use Python (#114). 40 files, 6,565 lines. `gen_reset`, the icons, the Android helpers, the mod tools, the price writer, the crests and the audio synth moved to Lobster or shell. The map generators and one-off concept scripts were retired instead.

**How it was checked.** Each port against the Python's own output. `gen_reset`: only the header line differs. Crests: 13 SVGs, byte for byte. Prices: the same diff on a made-up price set. The synth carries its own Mersenne Twister so the seeds mean what they did: all 163 WAVs but one match the committed files byte for byte, all 18 music stems decode to the same samples (only Ogg's random stream serial differs), and a render takes about 10 s.

**Decisions.** D-211. Better PNG compression later: #118.

**Funny moments.** The one WAV that differed, `built_1.wav`, turned out to be stale: the Python and the Lobster agree with each other, the committed file is from an older recipe. Left as it is, so a re-render will change that one sound. And a job list that lost 160 of 182 files because `xargs -L1` treats a trailing space as "this line continues"; "sfx chop " swallowed the next job, and the full render looked suspiciously quick.

**Ideas parked.** Two of the retired generators, Old Forest and River Delta, already failed their own crossing check, so they couldn't have rebuilt their maps anyway. `path_audit` is the reachability check left.
